# Archive

This folder holds historical and superseded documentation and records — ADRs
that have been replaced, plans and proposals for phases that have already
finished, migration guides for migrations that already completed, and similar
material that no longer reflects how the project currently works.

**Do not use anything under this folder to understand the current state of the
project or to guide new work.** Content here reflects past decisions, plans,
or state at the time it was written, and may directly contradict what's true
today. Contributors and coding agents (including Claude) should treat
everything in `docs/archive/` as historical context only — useful for
understanding *why* something changed, never as a source of current truth.
For the current state of the project, see the root `README.md`/`CLAUDE.md`
and the active documentation under `docs/`.
